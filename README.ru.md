# Netis NX31: Настройка прозрачного туннеля VLESS/Reality

Легковесный, оптимизированный по памяти скрипт настройки OpenWrt, предназначенный для развертывания прозрачного прокси-туннеля с использованием Xray (VLESS + Reality) и Redsocks в целях тестирования и обучения.

Проект был специально разработан и оптимизирован для роутера **Netis NX31** (MediaTek MT7981, 256 МБ ОЗУ, OpenWrt 21.02, ARM64). Основные концепции могут быть адаптированы для других маломощных устройств на OpenWrt в лабораторных условиях.

## 🌟 Ключевые особенности

* **Прозрачный прокси:** Перенаправляет TCP-трафик LAN-клиентов через Xray для анализа сети и тестирования.
* **Обработка UDP/QUIC:** Блокирует UDP 443, заставляя браузеры переключаться на TCP 443 для обеспечения стабильной маршрутизации во время настройки.
* **DNS over HTTPS (DoH):** Использует `https-dns-proxy` и исправляет ошибки DNS стоковой прошивки (удаляет мертвый fallback `127.0.0.1#5053`).
* **Оптимизация ОЗУ:** Запускает бинарник Xray на Go с параметрами `GOMEMLIMIT=50MiB` и `GOGC=20`, чтобы предотвратить падение из-за нехватки памяти (OOM) на роутерах с 256 МБ ОЗУ.
* **Пользовательский веб-интерфейс (CGI):** Предоставляет легкий интерфейс `/cgi-bin/vless` для обновления конфигураций без перезагрузки роутера.

## ⚠️ Отказ от ответственности и совместимость

**Этот скрипт сильно кастомизирован под Netis NX31 (или его идентичные клоны).** Не запускайте его вслепую на других роутерах. Если вы используете другое устройство или стандартную сборку OpenWrt, вы **должны** адаптировать следующее:
1. **Интерфейс WAN:** Замените `eth1` на ваш реальный WAN-интерфейс (например, `wan`, `pppoe-wan`) в файле `firewall.user`.
2. **Архитектура:** Убедитесь, что бинарник `xray` соответствует архитектуре вашего процессора (в этом репозитории предполагается `aarch64`).
3. **Веб-интерфейс:** Файлы HTML/JS адаптированы под стоковый веб-интерфейс Netis. Если вы используете LuCI, интеграция с интерфейсом работать не будет.

## 📋 Предварительные требования

Для автоматизации развертывания проект использует официальные утилиты командной строки от **PuTTY**: `plink.exe` (для SSH) и `pscp.exe` (для SFTP).
* **Автоматически:** Вам не нужно скачивать их вручную. Скрипт `nx31.bat` автоматически загрузит их с [официального сайта PuTTY](https://www.putty.org/) при первом запуске.
* **Вручную (если автозагрузка не удалась):** Если ваш компьютер блокирует загрузку через PowerShell, скачайте `plink.exe` и `pscp.exe` (64-bit) вручную и поместите их в ту же папку, что и `nx31.bat`.

*(Примечание: Эти исполняемые файлы намеренно исключены из репозитория через `.gitignore` в целях безопасности и экономии места).*

## 🚀 Как использовать (Windows)

1. **Получите ссылку VLESS:** Убедитесь, что у вас есть рабочая ссылка VLESS Reality для вашей тестовой среды.
2. **Настройте скрипт:** Откройте `nx31.bat` в текстовом редакторе и замените переменную `DIRECT_URL` на вашу реальную ссылку VLESS.
3. **Подключитесь к роутеру:** Подключите ПК к роутеру Netis NX31 через LAN или Wi-Fi.
4. **Запустите установщик:** Дважды щелкните `nx31.bat`. 
   * *(При первом запуске)* Скрипт автоматически скачает `plink.exe` и `pscp.exe`, если их нет.
   * Затем скрипт настроит репозитории `opkg`, загрузит все необходимые скрипты/конфиги, выполнит настройку и перезагрузит роутер.
5. **Доступ к интерфейсу:** Через 2–3 минуты откройте браузер и перейдите по адресу `http://192.168.1.1/vless.html`.

## 📁 Структура проекта

* `nx31.bat` — Основной скрипт установки для Windows (автоматизирует SSH/SFTP и скачивает зависимости).
* `setup.sh` — Основной скрипт настройки роутера (выполняется на OpenWrt).
* `firewall.user` — Постоянные правила `iptables` для NAT, прозрачного прокси и обработки UDP 443.
* `vless.cgi` / `vless.html` — Легкий веб-интерфейс CGI для управления.
* `xray-updater.sh` / `xray-watchdog.sh` — Фоновые скрипты для обновления конфигураций и поддержания работы Xray.
* `config.template.json` — Шаблон конфигурации Xray.

## 🛡️ Безопасность

В этом репозитории используется строгий `.gitignore`, чтобы предотвратить случайную загрузку:
* Вашего файла `urls.txt` (который содержит ваш приватный UUID VLESS и IP-адрес сервера).
* Исполняемых файлов (`plink.exe`, `pscp.exe`).
* Тяжелого бинарника Xray.

**Никогда не загружайте свои реальные VLESS-ссылки в публичный репозиторий.**
