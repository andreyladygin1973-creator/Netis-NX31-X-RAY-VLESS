# Version 1 (архив)

Здесь лежат файлы первой версии проекта — ровно те, что были до переработки
(супервизор цепочки, атомарная запись конфига, резервный DNS, чёрный ящик).

Точная копия этой версии доступна тегом git: `git checkout v1.0`.

## Отличия от тега `v1.0`

Только обезличивание — логика не менялась:

* пароль роутера заменён на `YOUR_ROUTER_PASSWORD`;
* IP прокси-сервера заменён на `203.0.113.10` (документационный диапазон RFC 5737).

## Чего здесь нет

Бинарник `xray` (aarch64) не дублируется — он один, в корне репозитория.
Чтобы запустить установщик из этой папки, скопируйте его сюда:

```bash
cp ../xray ./xray
```
